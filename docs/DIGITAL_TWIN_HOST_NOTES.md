# 上位机数字孪生预览说明

## 当前已接入内容

- 在上位机“打印 / 终端”页面新增“数字孪生预览”标签页
- 载入 G-code 后，同步显示打印轨迹、已执行轨迹、当前 TCP 位置和简化机械臂姿态
- 打印发送过程中，预览会随着当前 G-code 行推进
- 如果机械臂串口反馈中包含关节角或 TCP 字段，界面会优先采用真实反馈覆盖名义仿真状态

当前支持的反馈格式示例：

```text
STATE idx=35 status=RUN q=10.2,45.1,-32.0,0.0,20.0,5.0 tcp=260.1,-34.5,110.2
[PC][100][10.20 45.10 -32.00 0.00 20.00 5.00]
```

## 当前模型边界

- DH 尺寸目前采用课程设计阶段的名义参数，目的是先让上位机具备完整演示和联调能力
- 关节限位角目前仍属于示例 / 名义值，只能用于仿真预警，不能直接当作最终机械安全限位
- 机械臂外观目前为简化连杆模型，后续可以替换为真实 CAD、URDF 或 STL 外观
- TCP、打印平台和机械臂基座之间的坐标变换仍需实测标定

## 后续必须标定的内容

- 六个关节的机械零位
- 六个关节的真实正负限位角
- 机械臂基座坐标系到打印平台坐标系的变换
- 喷嘴相对末端法兰或末端执行器的真实偏置
- 实际串口反馈协议中的当前行号、关节角、TCP 和运行状态字段

## 答辩时建议怎么描述

建议表述为：

> 当前上位机已经预留并接入数字孪生 / 打印过程预览模块，可以在打印前对名义路径进行范围检查，在打印过程中同步显示 G-code 执行进度、喷嘴位置和机械臂姿态。现阶段使用课程设计的 DH 参数和待标定的名义限位完成软件闭环展示，后续可通过结构实测与零位标定替换为真实限位和真实坐标映射。
