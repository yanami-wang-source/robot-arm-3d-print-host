# 演示模型说明

## 推荐主展示件

当前最推荐的主展示件是 `demo_solid_spatial_arch_beam.gcode`。

- 优点：它不是单纯的稀疏桁架，而是由上下两层非平面拱形轮廓和横向填充共同形成的空间实体感梁体，更适合回答“机械臂 3D 打印能不能做出更像实体的结构”这个问题
- 展示重点：空间非平面路径、斜向连续成形、反重力倾斜段、多关节协同姿态变化

## 曲线桥展示件

`demo_spatial_truss_bridge.gcode` 现在已经改成参数化生成的连续曲线桥，而不是几段折线硬拼出来的示意轨迹。

- 前后两道主拱采用连续曲线采样，桥形更自然
- 横向连接和交叉斜撑基于拱上采样点生成，更像真实的空间桁架桥
- 挤出量按段长自动计算，轨迹和材料分配更合理
- 适合用来强调机械臂打印在空间曲线、悬空路径和多姿态协同上的优势

## 答辩时重点看什么

- `数字孪生 / 3D 打印过程预览`
  - 看机械臂如何跟随空间轨迹联动，而不是只在平面内扫线
- `G-code XY 预览`
  - 挤出段与空运行段分色显示，可直接说明工艺路径是分阶段组织的
- `G-code 终端`
  - 可辅助展示离线回放信息、名义电机输出和轨迹执行过程

## 一句话概括

这个展示件不是为了追求花哨，而是为了更清楚地表现机械臂 3D 打印相对传统三轴打印的三件事：

1. 空间非平面成形能力
2. 倾斜 / 反重力轨迹能力
3. 多自由度姿态协同能力
